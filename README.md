## Requisitos previos

Para ejecutar este proyecto se requiere tener instalado Node.js

## Instalación de dependencias

Una vez clonado el repositorio, ejecutar el comando npm install. Lee el archivo package.json e instala todas las herramientas necesarias en la carpeta node_modules.

## Ejecutar las pruebas

Para correr todos los tests del proyecto, ejecutar comando npm test

## Generar el reporte de cobertura

Para ver qué porcentaje del código está cubierto por los tests, ejecutar comando npm run coverage

## Estructura del proyecto

src/ :  clases del juego como piezas, tablero, reloj y Tetris.
tests/ : pruebas unitarias de cada clase.
